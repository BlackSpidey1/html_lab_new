HTML Fundamentals

HTML gives a webpage structure. It tells the browser what a heading, paragraph, list, link, image, or form is.

What is HTML?

HTML stands for HyperText Markup Language. It is the foundation of a webpage. It tells the browser: “This is a heading, this is a paragraph, this is an image, and this is a link.”

Simple explanation

Think of HTML like the structure of a house. The walls, rooms, roof, and doors give the building shape. HTML gives a webpage its structure.

HTML element example

<h1>Hello, world!</h1>
<p>This is my first webpage.</p>
Tip: The browser reads HTML and turns it into content that users can see and interact with.

What does this mean?

  • <h1> starts a heading.
  • Hello, world! is the visible content.
  • </h1> closes the heading.

Common beginner mistake

Beginners often forget to close tags. If a tag is left open, the browser may format the page incorrectly.
