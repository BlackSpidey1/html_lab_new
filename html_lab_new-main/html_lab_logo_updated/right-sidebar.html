CSS Fundamentals

CSS makes webpages look good. It controls colors, spacing, layout, fonts, backgrounds, and responsiveness.

What is CSS?

CSS stands for Cascading Style Sheets. HTML gives the content structure, and CSS gives that content style. It decides how the page should look.

Simple explanation

If HTML is the skeleton of a webpage, CSS is the paint, layout, spacing, and visual design.

CSS syntax

h1 {
  color: #7c9cff;
  font-size: 2.5rem;
  text-align: center;
}
  • h1 is the selector.
  • color is the property.
  • #7c9cff is the value.
Tip: CSS rules can be reused across many elements, which helps keep your page consistent.

Why do we need CSS?

Without CSS, a webpage would be plain and difficult to read. CSS helps create a better visual hierarchy, comfortable spacing, and a polished design.

Common beginner mistake

New developers often forget the semicolon at the end of a CSS property. Without it, the browser may ignore the rule.
